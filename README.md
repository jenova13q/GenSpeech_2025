# HW1 — Log-Mel + CNN (YES/NO)

## Что сделано
- Датасет: **Google Speech Commands** (оставлены только классы **YES** и **NO**).
- Свой слой признаков: **`LogMelFilterBanks`** (из первого ноутбука) — используется в модели.
- Модель: компактная **CNN (Conv1d)** ≤ 100k параметров.
- Обучение/валидация/тестирование + эксперименты:
  - `n_mels ∈ {20, 40, 80}`
  - `conv_groups ∈ {1, 2, 4, 8, 16}`
- Собраны метрики и ресурсы: **accuracy, loss, #params, FLOPs (CNN-часть), время эпохи**.
- Построены графики и сделаны выводы.

## Данные
- Источник: `torchaudio.datasets.SPEECHCOMMANDS`
- Фильтрация по меткам: `YES` и `NO`
- Разбиение: штатные train/valid/test из датасета

## Признаки
- Свой класс `LogMelFilterBanks` (Hann, STFT power spectrum, мел-фильтры, логарифм).
- Параметры по умолчанию: `n_fft=400`, `hop_length=160`, `sr=16000`, `n_mels` — варьируется.

> Примечание: в подсчёте FLOPs мы **не учитывали LogMel-экстрактор**, так как `thop` не поддерживает его напрямую. FLOPs посчитаны **только для CNN-блока**. Тенденция по FLOPs совпадает с уменьшением числа параметров при росте `groups`.

## Модель
- Два Conv1d-слоя → AdaptiveAvgPool1d → Linear(128→1)
- Активации ReLU, сигмоида в метриках (BCEWithLogitsLoss)
- Параметры `conv_groups` варьируются

## Тренировка
- Оптимизатор: Adam, `lr=1e-3`
- Эпох: 10
- Устройство: CPU (если нет GPU)
- Логгинг: Lightning + TensorBoard

## Короткие выводы
- **Лучший тест-результат:** `n_mels=80, groups=1` (≈ **98.4%**).  
  (при `n_mels=40, groups=1` тоже стабильно высокая точность ≈ 98.2–98.4%)
- **Группы (groups):** сильно уменьшают #параметров и FLOPs, но заметно ухудшают точность (особенно при 8–16 группах).  
- **Время эпохи на CPU** почти не меняется с ростом `groups` (бутылочное горлышко — подготовка признаков/дата-лоадер).
- **FLOPs** посчитаны **только для CNN-блока** — этого достаточно, чтобы показать тренд уменьшения вычислений при росте `groups`.

**Рекомендация:**  
- Для максимальной точности — `n_mels=80 (или 40)`, `groups=1`.  
- Для компактной модели — `n_mels=80`, `groups=4–8` (точность ~96–96.2%, параметры 5–10K).
